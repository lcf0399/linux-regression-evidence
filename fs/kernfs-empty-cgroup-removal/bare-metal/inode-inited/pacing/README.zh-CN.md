# INODE_INITED：预热与间隔诊断

2026-09-14，完成一次有界四点诊断：216 份程序样本、6,912 次正式
`mkdir() → stat() → rmdir()` 操作。六个条件下，删除均节省 **2.10～2.58 µs**。
预热 16 次、连续执行时，整段耗时减少 **5.77%～8.76%**，最大 CV 1.76%，启动间漂移均低于 2%。

这与[原实验及 128 次辅助实验](../README.zh-CN.md)分开。旧的不稳定结果保留，不覆盖、不合池；
不据此声称实际应用收益或完整并发安全。

## 固定条件

- A：`2f0c1cf72f4682178506f513bbf015e591b1aa4a`（7.3-rc2）＋Shakeel 文件句柄入口读锁修复。
  B：A＋T.J. 原版 INODE_INITED。复用[相同构建与补丁](../README.zh-CN.md)。
- i7-12700KF 裸机、CPU0、sched_ext 关闭、full 抢占、performance governor、Turbo 关闭。
  [本轮身份](identity.json)记录源码、binary、配置和四个独立启动点。
- A1 → B1 → B2 → A2；每点六条件，每条件九份样本，每份正式测量 32 次。
  预热 0／16 次，操作前间隔 0／50／200 ms，全部在计时前固定。
- 128 改为 32 是为了限制间隔诊断的耗时，不是事后挑选样本。
- 等待在整个操作计时之前，以下数字已排除等待。完整操作包含计时调用和用户态衔接，
  不包括父目录准备、删除后的状态检查，以及全部异步回收成本。
- 另存的 `workload_wall_per_cycle_ns` 包含等待和循环检查，不用它比较跨间隔的内核操作成本。

“连续”是指同份样本内不额外等待；仍有启动后 45 秒稳定等待和程序调用之间 2 秒间隔。
不预热仅省去练习操作，父目录准备仍执行，不保证缓存冷。

## 删除结果

下表 A／B 分别列 A1／A2、B1／B2，单位 µs；每个值为九份样本均值的中位数。
降幅覆盖全部四种 B/A 端点组合，不是置信区间，也不只挑最有利的一对。

| 预热／间隔 ms | A，µs | B，µs | 降幅 | 最大 CV |
| --- | --- | --- | --- | --- |
| 0／0 | 10.125／10.018 | 7.852／7.819 | 21.62%～22.77% | 0.94% |
| 16／0 | 9.758／9.755 | 7.596／7.544 | 22.13%～22.69% | 0.93% |
| 0／50 | 18.229／18.126 | 15.854／15.694 | 12.53%～13.91% | 1.76% |
| 16／50 | 18.129／18.024 | 15.926／15.789 | 11.64%～12.91% | 1.67% |

| 16／200 | 18.171／18.332 | 15.846／15.756 | 12.79%～14.05% | 2.45% |

所有删除条件满足 CV≤3%、重复启动漂移≤2%；drop-first 后仍快至少 5%。
drop-first 仅在敏感性检查中去掉每点第一份完整样本，原始样本没有删除。

间隔使删除基线从约 10 µs 增到 18 µs，但绝对节省仍为 2.10～2.58 µs，因此百分比变小。
50→200 ms 没有再次让基线接近翻倍。这个诊断检查降低调用频率后收益是否仍存在；
这些间隔不是实际应用的推荐参数。

16／0 通过稳定性检查：A／B 漂移 +1.92%／+1.33%，drop-first 仍快 5.60%～8.64%。
这不能证明“减少到 32 次”就是波动降低的原因。0／0 仍不稳定，降幅仅为参考值。
间隔条件的整段计时均通过稳定性检查，但改善低于预设 5% 效应门槛，不等于没有收益。

mkdir/stat 单项及初始操作结果均保留。例如 16／0 的 mkdir A 漂移 +2.78%，stat 最大 CV 5.50%，
不能因整段稳定就精确量化每一阶段的变化。六条件的首次单次比较均有噪声；首次、前四次、
后 28 次与完整样本存在重叠，不是新的独立样本。

本轮未测 cache miss 或 syscall 计时段的实际 CPU 频率，不能拆分缓存/TLB、频率响应、回收的
各自贡献。CV 更低不代表绝对波动更小，也不代表更接近实际应用。

## 命中与复现

两端独立非计时准入共 24 份 smoke/trace 记录，每份四次操作、无预热。
48 次被跟踪操作显示：每次删除仍有 26 个 kernfs 节点，`ilookup()` 从 26 次降到 1 次；
首次 stat 新增一对写锁。`kernfs_init_inode` 被合并进 `kernfs_get_inode`，独立符号计数为零
不代表没命中初始化。见[机制计数](mechanism.json)。正式计时不带跟踪，两阶段结束均恢复 generic。

[源码](reproducer/control.c)与实际编译输入逐字节一致；只比旧辅助程序多允许 200 ms 间隔并改变
schema，操作顺序和计时不变。共享头文件、补丁和验证器的 SHA 见[来源记录](provenance.json)。
在 `reproducer/` 中执行 `make`，然后在专用匹配主机运行连续预热条件：

```sh
sudo env -u CG_GRAPH -u CG_TRACE CG_SCX_DISABLED=1 CG_CYCLE_PACE_MS=0 \
  ./build/control unused leaf 0 0 0 0 32 16
```

间隔改 `CG_CYCLE_PACE_MS=50` 或 `200`，不预热改最后一个参数为 `0`。程序创建独立 cgroup
子树，不在共享生产主机运行。重新编译后应记录新 binary SHA，不能假设与历史构建相同。
