# 同 CPU 同步交接与 delayed requeue 计账

2026-09-21 候选材料，尚未提交上游。撤回提交只用于归因，**不是修复建议**，
也没有上游接受或合入的结论。

在所测 v7.2 上，仅撤回 `333238da9a19` 后，两线程完整往返在不加计算／轻计算时分别
缩短 11.31%／9.58%；计算量较大时缩短 2.86%。加入第三个忙线程后，没有观察到稳定的
明显优势。目前没有真实应用影响测量，也不能证明撤回保留了调度公平性。

## 测了什么，原因是什么

两个 nice 0、SCHED_OTHER 线程固定在 CPU 2，使用 private futex WAIT/WAKE 交替交接。
各线程每次交接前做 0／256／4096 次有依赖的整数运算；完整往返含两次交接。
每档分别无／有同 CPU 第三个持续计算线程，共六组。线程创建、初始设置、协议和结果
校验均在计时之外。后台比较每秒运算量，不比较不同时间窗口内的累计运算量。

[原提交](attribution/333238da9a19.patch)在重新入队前补上 `update_curr(cfs_rq)`，
目的是依据更新后的计账计算 lag，而不是继续使用旧状态。它不仅多做一次调用，也会
改变调度选择：无忙线程时，原版约 2 WAIT/往返，撤回版在三档计算量下约
1.14／1.10／1.02。因此差距不能解释成一次 `update_curr()` 的纯执行成本。

独立命中运行每次观察 1000 次往返：原版无忙线程时有 1994–2000 次 delayed requeue，
有忙线程时只有 1–3 次。原版每次观察到的 requeue 均包含内部计账调用，撤回版为零。
这是独立探针结果，不是干净计时中的精确频率；后台速度相近也不能证明原先频繁
requeue 条件下的公平性。

另有使用早期纯交接程序的[固定状态抽样](attribution/placement-sample-summary.json)：
每内核、每 nice 条件取 32 次。原版 nice 0／+5 都有 31/32 次重新排位、32/32 次选择当前
线程；撤回版没有重新排位，分别有 23/32、21/32 次选择被唤醒线程。抽样位置提前固定，
这些比例不是无探针总体频率，也不能分解时间差各占多少。

[独立 v7.3-rc4 纯交接补测](bare-metal/handoff-only-7.3-rc4-summary.json)将未修改的
`93f51579e7df` 夹在两次 v7.2 启动之间，nice 0／+5 的完整往返分别变化 +0.121%／−0.568%，
最大 CV 0.377%、漂移 0.130%，仍约 2 WAIT/往返。这次使用早期程序，每次调用预热三轮，
每条件每启动共九轮正式观测；不与下面的固定计算量矩阵混算。

## 完整结果

原版 A → 仅撤回版 → 原版 B，三个独立启动。i7-12700KF，20 个逻辑 CPU 在线；
实际 full 抢占，performance governor/EPP，Turbo off。同 GCC 15.2.0，配置项只差
LOCALVERSION。每条件每启动三次调用，各预热 1 轮、正式 3 轮，每轮 100,000 次往返。
每条件每启动九份观测，六条件合计 162 份；没有丢弃波动较大的组。

单位 ns/roundtrip；差异以原版 A/B 均值的中点为分母，负数表示撤回版更快。
最大 CV 同时考虑九轮合并和每份三轮；冻结标准为 CV ≤2%、漂移绝对值 ≤2%、效应 ≥5%。

| 忙线程 | 每次交接计算次数 | 原版 A | 撤回版 | 原版 B | 差异 | 最大 CV | B/A 漂移 |

| 无 | 0 | 2203.878 | 1953.822 | 2201.938 | −11.307% | 0.940% | −0.088% |
| 无 | 256 | 2758.329 | 2491.302 | 2751.968 | −9.577% | 0.233% | −0.231% |
| 无 | 4096 | 11350.495 | 11026.134 | 11351.376 | −2.861% | 0.099% | +0.008% |
| 有 | 0 | 3993.389 | 4200.725 | 4063.397 | +4.278% | 4.447% | +1.753% |
| 有 | 256 | 5142.982 | 5004.522 | 4985.720 | −1.181% | 3.500% | −3.058% |
| 有 | 4096 | 21525.327 | 21538.822 | 21489.921 | +0.145% | 0.498% | −0.164% |

有忙线程的前两组不稳定，不能把百分比作为精确效应；第三组稳定但基本不变。
三组后台每秒运算量变化均不足 0.11%。去掉每份第一轮后，无忙线程三档差异仍为
−11.263%／−9.502%／−2.879%。运行结束已恢复 generic 和原电源状态。
