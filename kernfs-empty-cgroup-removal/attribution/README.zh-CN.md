# 非计时证据与本地 root 复用原型

原修改补齐通知和并发语义。有功能目的，不代表作者已给出延迟预算，也不代表新增操作
全部无法优化。这里不建议撤销修复或直接跳过 inode 查找。

`root-reuse.patch` 是在 `eea5d2bb34ba11dccd9c53f392dc50cf060150a9` 上实测的原型。
每次内部删除调用取一次 root，再传给链接计数辅助函数。保留锁及顺序、inode 查找、
链接计数清零、通知、时间戳和引用操作，不跨放锁缓存可能变化的 parent 或 superblock 列表。

原 tree 为 `e2368bca2521f1371e1c7f11a6dfa712b1f05c87`，原型 tree 为
`6bc9d9e5519688749cd37f58dca937f77bd9ba45`。补丁 SHA-256：
`95eb05b20b91886f9b889a06cdc51742b25d6a290ee331b86d40e06fa8d9c6ae`。

非计时检查仍为 26 次 inode 查找、52 次属性写锁、26 次包装层读锁。
删除函数和包装层合计 RCU 成对入口从 234 降为 78，但不能按次数比例推算性能。
独立干净计时只见约 4%～5% 小幅收益，见[裸机数据](../bare-metal/original-regression/README.zh-CN.md)
中的 `root-reuse-r1`，不把不同实验的绝对值相减来声称追回多少总回归。

已测通知、打开 FD 的链接计数清零、同 superblock 的 namespace 别名及有界并发读删；
未测真正多 superblock、运行时 lockdep。开启 lockdep 的对象编译通过不代表运行验证通过。
创建变化为 −0.265%～+3.150%；一个派生删除比值 CV 为 3.050%，不作可靠解释。
这是局部原型，不是完整修复或已提交补丁，也没有在固定 7.3-rc2 上测试该原型的收益。

独立返回值 probe 已确认多数查找为空，但没有得到简单安全的跳过条件。
没有打开 FD/watch、引用计数较小或先前查找为空，均不能排除已有或并发建立的 inode。
更强的方案需要状态发布、生存期和多 superblock 同步设计，目前未实施。
